# Тесты

```sh
yarn test              # весь набор
yarn test --watch      # в режиме наблюдения
yarn test visible-range # по имени файла
yarn check             # линт + типы + тесты
```

**67 наборов, 795 тестов.** Прогон занимает около секунды.

## Как устроено

`testEnvironment: node`, RN-рантайм не поднимается: тестируется логика ядра.

Трансформ — babel с пресетом React Native **без** плагина Reanimated
(`babel-jest.config.js`). Директивы `"worklet"` остаются строками, worklet-код
вызывается как обычные функции.

## Чего тесты не проверяют

- **Отрисовку** — нужен RN-рантайм с работающим `ScrollView` и реальными
  `onLayout`.
- **Нативное удержание позиции** — тесты доходят до позиции распорки, дальше
  работает `ScrollView`.
- **Кадры и производительность** — автоматических порогов по замеру нет.
- **Согласие с нативной раскладкой** — расчёт низа под `insetEnd` покрыт
  целиком, попадание сдвига в нужный кадр — нет.

Это проверяется стендами в [`example/`](../example), по одному на механику.

## Добавление тестов

Тесты лежат в `__tests__` рядом с проверяемым кодом:

```
core/layout/
  visible-range.ts
  __tests__/
    visible-range.test.ts
```

Имя теста описывает поведение, а не метод:

```ts
it("не растит запас назад: там всё уже отрисовано", () => {
  // ...
});
```

Зависимости модулей передаются объектом опций, поэтому подмена в тесте — это
литерал, а не мок:

```ts
const range = computeVisibleRange({
  metrics,
  scroll: 1000,
  scrollLength: 500,
  drawDistance: 400,
  velocity: 2,
});
```
