# Ограничения

Чего `AnchorList` не делает.

## Чего нет

| Возможность | Причина |
| --- | --- |
| Горизонтальные списки | Геометрия написана под вертикальную ось |
| Несколько колонок, masonry | Раскладка одномерная: позиция элемента — сумма высот предыдущих |
| `inverted` | Та же задача решается прямо — см. [Миграция](migration.md#что-делать-вместо-inverted) |
| `RefreshControl` / pull-to-refresh | Своей поддержки нет; до `ScrollView` можно дотянуться через `refScrollView` |
| Секции (`SectionList`) | Данные — плоский массив; прилипающие заголовки делаются через `sticky` |
| Свайп по строке | Дело ячейки, а не списка |
| Перетаскивание строк | — |
| `flashScrollIndicators` | — |
| Анимации вставки и удаления строк | — |

## Обязательные условия

**Новая архитектура, React Native 0.78+, React 19+.** Reanimated 4 работает
только на новой архитектуре, а `AnchorList` — только с Reanimated 4+ и
`react-native-worklets` — см.
[Установка](installation.md#почему-reanimated-обязателен).

**Стабильные уникальные ключи.** Ключ не зависит от индекса, дубликаты не
допускаются.

**`estimatedItemSize`.**

**Явная высота списка.** `flex: 1` или конкретное число.

## Особенности поведения

**`ItemSeparatorComponent` входит в высоту ячейки.** Он рисуется внутри строки, а
не между строками; объявленные через `getFixedItemSize` размеры обязаны его
учитывать. В `FlatList` устроено иначе.

**`bounces` выключен** и не настраивается.

**`keyboardDismissMode` задаёт список** и не даёт его изменить: `interactive` на
iOS, `on-drag` на Android.

**Отдельного `onScroll` нет.** Смещение отдаётся через
`sharedValues.scrollOffset`.

**Объявленный размер необратим.** Размер из `getFixedItemSize` обратно в
оценочный не превращается: перевести список с объявленных размеров на
измеряемые можно только пересозданием (сменой `key`).

**Среднее по типу фиксируется после 32 замеров.** Строки одного типа с сильно
разной высотой лучше развести по разным типам.

**Пачка появившихся элементов ограничена 32 строками.** Если разом появилось
больше, они размещаются по среднему, без ожидания измерения.

**Первый показ ограничен по времени.** Без стартовой позиции и без новых замеров
список показывается через 150 мс; пока раскладка меняется, страховка ждёт до
десяти дополнительных кругов — около 1,65 секунды.

## Платформы

| Платформа | Состояние |
| --- | --- |
| iOS | Поддерживается |
| Android | Поддерживается |
| Web (`react-native-web`) | ⚠️ **Не работает** |

### Web требует доработок

Бандл собирается, список в браузере не работает. Удержание видимой позиции
выполняет нативный `ScrollView` через `maintainVisibleContentPosition`, а
`react-native-web` этого свойства не реализует.
