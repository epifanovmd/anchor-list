## Соглашения документации

**Координаты.** Всё, что список отдаёт наружу как позицию или размер, живёт в
координатах контента — тех же, в которых работает `contentOffset` нативного
скролла. Внутри есть ещё координаты элементов (они отличаются на высоту шапки),
но наружу они не выходят.

**Ось.** Список вертикальный. Везде, где сказано «размер», имеется в виду высота;
«длина вьюпорта» — его высота.

**Кромки.** `start` — начало контента (верх), `end` — конец (низ). Это касается и
прилипания, и порогов подгрузки, и стартовой позиции.

**Ключ важнее индекса.** Индекс элемента меняется при любой вставке выше него.
Всё, что должно пережить смену данных — измеренные размеры, привязки контейнеров,
якоря удержания позиции, — адресуется ключом.
