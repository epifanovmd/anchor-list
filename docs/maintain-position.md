# Удержание видимой позиции

Компенсация изменений выше вьюпорта: видимая строка остаётся на своём месте
экрана, когда над ней вставляются данные или растут уже отрисованные ячейки.

## Включение

```tsx
<AnchorList
  maintainVisibleContentPosition={{ data: true, size: true }}
  ...
/>
```

| Поле | По умолчанию | Компенсирует |
| --- | --- | --- |
| `data` | `false` | Вставку и удаление элементов |
| `size` | `false` | Изменение размеров уже отрисованных элементов |
| `shouldRestorePosition` | — | Выбор якоря восстановления |

Объект сравнивается по ссылке — мемоизируйте:

```tsx
const maintainVisibleContentPosition = useMemo(
  () => ({ data: true, size: true }),
  [],
);
```

Обе механики независимы. Ленте, растущей только вниз, не нужна ни одна.

## Как это работает

**Якорь снимается до изменения.** Якорем становится первый элемент, целиком
лежащий ниже кромки вьюпорта. Строки, торчащие над кромкой, берутся, только если
других во вьюпорте нет. Неизмеренные строки в якоря не годятся.

**Якорей снимается четыре.** Опорой становится первый переживший изменение.

**Сдвиг выполняет нативный `ScrollView`.** Ему передан
`maintainVisibleContentPosition={{ minIndexForVisible: 0 }}`, а первым ребёнком
контента лежит распорка нулевого размера: нативный код запоминает её кадр перед
mount-транзакцией и после неё добавляет смещение кадра к `contentOffset`.
Программный `scrollTo` не используется — он пришёл бы отдельным кадром и оборвал
жест.

**Величина сдвига накопительная**: нативный слой смотрит на смещение кадра
распорки между транзакциями.

**Сдвиг применяется целыми точками**, остаток меньше точки копится до следующего
прохода.

**Пачка измерений идёт одним проходом.** Якорь снимается до первого изменения
пачки и восстанавливается после последнего.

**Пока идёт доводка стартовой позиции, нативная компенсация выключена** —
абсолютным смещением до показа списка распоряжается только
[стартовая позиция](scrolling.md#стартовая-позиция).

### Компенсация размеров не работает на броске

Компенсация по `size` отключена, пока список идёт быстрее примерно трёх сотых
экрана в миллисекунду. Решение принимается в момент снятия якоря: якорь, снятый
на спокойном скролле, доводится до конца, даже если список успел разогнаться.

Компенсация по `data` работает на любой скорости.

## `shouldRestorePosition`

Выбор якоря восстановления. По умолчанию — первый видимый элемент, подходящий по
условиям выше.

```tsx
maintainVisibleContentPosition={{
  data: true,
  size: true,
  // Спиннеры и разделители исчезают вместе с тем изменением, ради которого
  // якорь и снимался.
  shouldRestorePosition: item => item.type === "message",
}}
```

Функция вызывается для каждого кандидата сверху вниз; возврат `false` исключает
элемент.

## Что видно в замере

Строка `mvcp` встроенного замера
([Производительность](performance.md#встроенный-замер)):

```
  mvcp      12 захватов · 12 восстановлений (данные 8 / размер 4) · на броске пропущено 0 · второй проход 3 · сдвиг 340/1204px
            упор 0 · потеряно 0/0px · без якоря 0 · запасной якорь 2 · промах 0 на 0/0px
```

| Величина | Что значит |
| --- | --- |
| `захватов` / `восстановлений` | Сколько раз якорь снимался и применялся |
| `данные` / `размер` | По какой из двух причин |
| `на броске пропущено` | Замеров, не снявших якорь по скорости |
| `второй проход` | Сдвиг разошёлся с предсказанным, раскладка посчитана заново |
| `сдвиг` | Средний и максимальный сдвиг, px |
| `упор` | Компенсация уперлась в границу скролла |
| `потеряно` | Сколько пикселей сдвига не применилось |
| `без якоря` | Ни один кандидат не подошёл |
| `запасной якорь` | Первый кандидат не пережил изменение, взят следующий |
| `промах` | Позиция после восстановления разошлась с ожидаемой |

`упор`, `без якоря` и `промах` в норме нулевые — иначе см.
[Симптомы](troubleshooting.md).

## Ограничения

**Работает только выше вьюпорта.** Изменения ниже видимой части ничего не
двигают.

**Опирается на нативный `maintainVisibleContentPosition`.** В браузере не
работает — см. [Ограничения](limitations.md#web-требует-доработок).

**Нужны стабильные ключи.** Якорь адресуется ключом; меняющийся вместе с
элементом ключ даёт `без якоря` в замере.

**Сдвиг упирается в границу скролла** — в замере это `упор` и `потеряно`.
