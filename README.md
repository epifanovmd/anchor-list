**Виртуализированный список для React Native, рассчитанный на ленты, которые
растут в обе стороны.**

`AnchorList` держит на месте не «экран», а конкретную строку. Когда сверху
приезжает страница истории, когда картинка догрузилась и раздула ячейку выше
вьюпорта, когда клавиатура съела низ экрана — то, на что смотрит пользователь,
остаётся ровно там, где было.

```tsx
import { AnchorList } from "@epifanovmd/anchor-list";

<AnchorList
  data={messages}
  renderItem={({ item }) => <Message message={item} />}
  keyExtractor={message => message.id}
  estimatedItemSize={92}
  maintainVisibleContentPosition={{ data: true, size: true }}
  onStartReached={loadOlder}
/>;
```

---

## Зачем он нужен

`FlatList` рассчитан на ленту, которая растёт вниз. Переписка растёт вверх, и
почти всё сложное в ней — следствие этого:

| Что происходит | Что видит пользователь без компенсации | Что делает `AnchorList` |
| --- | --- | --- |
| Подгрузилась страница истории | Контент прыгает вниз на высоту вставленного | Удерживает видимую строку: `maintainVisibleContentPosition.data` |
| Ячейка выше вьюпорта изменила высоту | Экран уезжает на дельту | Компенсирует по размеру: `maintainVisibleContentPosition.size` |
| Открылась клавиатура | Последнее сообщение уходит под панель ввода | Отступ анимируется на UI-потоке, индикатор скролла — вместе с ним |
| Переход к цитате у конца переписки | Скролл упирается в границу, цитата встаёт не у кромки | Резервирует место распоркой: `anchoredEndSpace` |
| Заголовок даты у верхней кромки | Прилипший заголовок дрожит на быстром скролле | Пока заголовок стоит у кромки, его рисует слой поверх списка — без покадрового трансформа |

## Что умеет

- **Удержание видимой позиции** — по данным и по размерам, с выбором якоря.
  Сдвиг выполняет нативный `ScrollView` в той же транзакции, что и раскладку,
  поэтому промежуточного кадра не возникает и жест не обрывается.
- **Прилипающие якоря на обеих кромках сразу** — заголовки дат сверху и аватары
  групп снизу, в двух режимах: прилипает вся строка или только объект внутри неё.
- **Состояние на UI-потоке** — 25 значений (`scrollOffset`, `velocity`,
  `isNearEnd`, `firstVisibleIndex`, …) отдаются shared values: индикатор
  прокрутки, кнопка «вниз» и тени кромок анимируются без единого рендера.
- **То же состояние в React** — через `useAnchorListState`, с адресной
  подпиской: перерисовывается только тот, чьё значение изменилось. Читать можно
  из компонентов снаружи списка и до того, как он смонтируется.
- **Подгрузка в обе стороны** — с порогом в долях вьюпорта, гистерезисом у
  границы и общим гейтом, который не даёт двум кромкам выстрелить на одном жесте.
- **Стартовая позиция** — по индексу, ключу, смещению или концу списка. До неё
  список не показан: пользователь не видит кадра, посчитанного по оценкам.
- **Переработка контейнеров** по типам строк, известные заранее размеры,
  буфер отрисовки, растущий со скоростью броска, и встроенный замер
  производительности.
- **Видимость элементов** — несколько независимых наборов порогов на одном
  списке, с выдержкой `minimumViewTime`.

## Как устроен

Диапазон отрисовки, позиции и привязка контейнеров считаются вне React. В дерево
уходят адресные сигналы: скролл, сдвинувший одну строку, перерисовывает один
контейнер, а не список. Сам компонент — тонкая оболочка над `ScrollView`.

## Производительность

На одинаковом наборе данных `AnchorList` обгоняет `FlashList` и `LegendList` и
держит больше кадров в секунду — в том числе там, где включено прилипание,
самая дорогая механика списка.

Замер воспроизводится стендом «Нагрузка» в [`example/`](example): тысяча
сообщений, подгрузка в обе стороны, измеряемые высоты и прилипающие к верхней
кромке даты. Счётчики печатаются раз в секунду, отдельной строкой — во что
обходится прилипание на каждом проходе. Как читать отчёт —
в [Производительности](docs/performance.md).

## Установка

```sh
yarn add @epifanovmd/anchor-list
```

Нужны `react-native-reanimated` (4+) и `react-native-worklets` — подробности и
настройка babel в [руководстве по установке](docs/installation.md).

## Пример

В [`example/`](example) — восемь стендов, по одному на механику: стартовая
позиция, подгрузка, компенсация, нижний отступ, прилипание, состояние, переход к
сообщению и нагрузка.

```sh
yarn
yarn example ios      # или android
```

> **Web пока не готов.** Бандл собирается, но список в браузере не работает:
> удержание позиции опирается на нативный `maintainVisibleContentPosition`,
> которого нет в `react-native-web`. Подробности — в
> [Ограничениях](docs/limitations.md#web-требует-доработок).
